```ts
// A Calimero Cloud cluster by name: its nodes come from the node directory,
// each attested under `policy` before anything is sent to it.
await CalimeroClient.connect({
  cluster: string,         // e.g. 'eu-shared-1'
  policy: CloudPolicy,
  directory?: string,      // default DEFAULT_DIRECTORY (Calimero Cloud's)
  zone?: string,           // try this zone's nodes first
  fetch?: typeof fetch,
  retry?: { retries?: number; baseDelayMs?: number; maxDelayMs?: number },
  random?: () => number,   // for the weighted order; default Math.random
}) // throws DirectoryError (reason 'unreachable' | 'not-found' | 'bad-response' | 'empty')

// A fixed list of nodes, or a cluster you run yourself.
new CalimeroClient({
  baseUrl: string,         // one node of the cluster
  nodes?: string[],        // other nodes, moved to on 421 WRONG_NODE or when one stays unavailable
  policy: CloudPolicy,     // which nodes to trust; see Trust and the sealed channel
  fetch?: typeof fetch,    // carries attestation and envelopes; default the global fetch
  retry?: { retries?: number; baseDelayMs?: number; maxDelayMs?: number }, // default 6, 200 ms, 2 s
})
```

`client.nodeUrl` is the node in use and `client.nodes` every node the client
may move to. Every route below is sent inside the sealed channel, but
`GET attestation` and `GET health`. `passkey` is a `PasskeyProvider`
(`browserPasskey()` in a page); a step-up takes `{ confirm: passkeyConfirm(passkey) }`.

## Flows and streams

The hand-written methods: each is more than one route, or a stream.

| Method | Routes |
| --- | --- |
| `signUp(passkey, name, { origin?, invite?, signal? })` → `CalimeroSession` (the new passkey is asked twice: to register, then to sign the account it creates; `SignUpRefused` when the policy or the invite refuses) | `POST auth/passkey/register/begin`, `…/finish` |
| `signIn(passkey, { origin?, signal? })` → `CalimeroSession` (`PasskeyUnknownHere` for a passkey this cluster does not know) | `POST auth/passkey/login/begin`, `…/finish` |
| `refresh()`, `signOut()`, `signOutEverywhere()`, `useSession(session)`, `useApiKey(key)` | `POST auth/refresh`, `auth/logout`, `auth/logout-all` |
| `addPasskey(newPasskey, approver)` → credential id | `POST auth/passkeys/add/begin`, `…/finish` |
| `startAccountRecovery(code, passkey)`, `finishAccountRecovery(passkey, accountId?)` | `POST auth/recovery/begin`, `…/start`, `…/finish` |
| `startRecovery(org, seed)` (the seed signs here) | `GET auth/me`, `POST orgs/{org}/recovery/start` |
| `downloadBlob(app, id)`, `downloadBlobGranted(app, id, grant)` → bytes | `GET apps/{app}/blobs/{id}` |
| `events(app, from?, signal?)`, `presenceStream(app, signal?)` → server-sent events | `GET apps/{app}/events`, `apps/{app}/presence/stream` |
| `appsReportAll(org)`, `pendingApprovals(org?)` | `GET orgs/{org}/apps` or `auth/apps` (every page), `GET releases` |
| `openConsentPage(request, navigate \| { navigate?, confirm? })`, `waitForConsent(requestId, { intervalMs?, signal?, expiresAt? })` | `POST consent/requests`, `GET consent/{request}/result` |

## The generated methods

Every route of the node is a method, generated from core's OpenAPI document
(`openapi/core-openapi.json`, by `pnpm gen:api` into `src/generated/`), in a
group per tag: `client.apps`, `client.auth`, `client.orgs`, `client.packages`,
`client.deployments`, `client.consent`, `client.ops`, `client.public`. Each takes
one typed argument object (path parameters, query and body fields merged; a raw
body under `body`, with `contentType`) and answers the route's typed payload; a
refusal is thrown as its typed `CalimeroError`.

```ts
import { passkeyConfirm } from '@calimero-network/mero-js';

const org = await client.orgs.get({ org: orgId });
await client.orgs.setMember({ org: orgId, account, role: 'member' }, { confirm: passkeyConfirm(passkey) });
```

The second argument, `{ confirm, operatorProof, signal }`, answers this call's
`412 CONFIRM_REQUIRED` or `428 OPERATOR_SIGNATURE_REQUIRED`;
`new CalimeroClient(options, { confirm, operatorProof })` answers every call that
gives none. Routes the document marks retry-safe are retried on `503` (D70), and
one that requires an idempotency key gets one. The event streams stay on the transport.
`createRoutes(createApiClient(transport))` builds the groups on any
`NodeTransport`.

`client.api` is the low-level `openapi-fetch` client they run on (`{ data,
error, response }`, with `stepUp` / `operatorSignature` middleware and `unwrap`),
kept as an escape hatch.

## The generated methods

Every route of the node is a method, generated from core's OpenAPI document
(`openapi/core-openapi.json`, by `pnpm gen:api` into `src/generated/`), in a
group per tag: `client.apps`, `client.auth`, `client.orgs`, `client.packages`,
`client.deployments`, `client.consent`, `client.ops`, `client.public`. Each takes
one typed argument object (path parameters, query and body fields merged; a raw
body under `body`, with `contentType`) and answers the route's typed payload; a
refusal is thrown as its typed `CalimeroError`.

```ts
import { passkeyConfirm } from '@calimero-network/mero-js';

await client.orgs.setMember({ org: orgId, account, role: 'member' }, { confirm: passkeyConfirm(passkey) });
```

`412 CONFIRM_REQUIRED` or `428 OPERATOR_SIGNATURE_REQUIRED`;

`client.api` is the low-level `openapi-fetch` client they run on (`{ data,
error, response }`, with `stepUp` / `operatorSignature` middleware and `unwrap`),
kept as an escape hatch.

## The runtime

Every request goes through `client.transport`, a `Transport` from
`@calimero-network/mero-js/runtime`: attestation, the sealed channel, the
session and its refresh, `421` moves, D70 retries, the `412` step-up, error
mapping and server-sent events, behind `request(method, path, options)`,
`json(method, path, options)` and `events(path, options)`; `exchange(method,
path, options)` answers a refusal as the node's response, which is what the
generated client sends through. `options` takes `query`, a JSON `body` or raw
`bytes` with `contentType`, a `passkey` that answers a `412 CONFIRM_REQUIRED`,
`retry` (`true` for a call or a view, `'once'` for a confirmed attempt) and
`signal`. `routePath('orgs/{org}', { org })` encodes the path's segments.
`new CalimeroClient(transport)` builds a client on a `NodeTransport` made
elsewhere.

## Not covered

- The rest of `/ops/*`, the operator's API: use core's `meroctl`.
- `/apps/{app}/attestation` and receipt verification (core's
  `Client::verify_app_cluster`, which checks every replica's receipt key and the
  cluster's governance): not yet in this client.
- `/internal/*`: node to node only.
