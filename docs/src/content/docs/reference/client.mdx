```ts
new CalimeroClient({
  baseUrl: string,         // one node of the cluster
  policy: CloudPolicy,     // which nodes to trust; see Trust and the sealed channel
  fetch?: typeof fetch,    // carries attestation and envelopes; default the global fetch
  retry?: { retries?: number; baseDelayMs?: number; maxDelayMs?: number }, // default 6, 200 ms, 2 s
})
```

Every route below is sent inside the sealed channel. `passkey` is a
`PasskeyProvider` (`browserPasskey()` in a page); a method that takes one
answers the node's `412 CONFIRM_REQUIRED` with it.

## Approvals and the consent page

The approval routes above refuse a session opened on an app's frontend
(`403`). An app sends its user to the node's consent page instead
([guide](/guides/user-approvals/)).

| Method | Route |
| --- | --- |
| `appsReport(org \| null, { after?, limit? })` → `AppsReport` | `GET orgs/{org}/apps` or `auth/apps` |
| `appsReportAll(org \| null)` → `AppsReport` (every page) | the same, following `next` |
| `releaseRules()` → `{ governance, deadlines }` | `GET releases` |
| `pendingApprovals(org?)` → `PendingApprovals` | `GET auth/apps` (or `orgs/{org}/apps`), `GET releases` |
| `requestConsent(request)` → `{ requestId, url, expiresAt }` | `POST consent/requests` |
| `openConsentPage(request, navigate?)` | `POST consent/requests`, then navigates to `url` |
| `consentResult(requestId)` → `{ requestId, kind, status, decidedAt }` | `GET consent/{id}/result` |
| `waitForConsent(requestId, { intervalMs?, signal?, expiresAt? })` | polls `GET consent/{id}/result` |

## Any route

`get`, `post`, `put` and `delete(path, body?)` send any request through the
sealed channel with the client's credential and map a refusal to a typed error.
`postConfirmed(path, body, passkey)` and `deleteConfirmed(path, passkey, body?)`
answer a `412 CONFIRM_REQUIRED`.

## Not covered

- The rest of `/ops/*`, the operator's API: use core's `meroctl`.
- `/apps/{app}/attestation` and receipt verification (core's
  `Client::verify_app_cluster`, which checks every replica's receipt key and the
  cluster's governance): not yet in this client.
- `/internal/*`: node to node only.
